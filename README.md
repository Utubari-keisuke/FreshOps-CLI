# FreshOps-CLI (店舗食材・賞味期限＆廃棄ロス管理システム)

カフェ・飲食店における仕込み品や食材の期限切れ廃棄を未然に防ぎ、ロス金額を可視化してコスト削減を支援するJava製CLI（コマンドライン）アプリケーションです。<br>
こちらは、後期審査会後にマネージャーに使ってもらおうと思っています。

---

## 開発背景・解決する課題

飲食・カフェの現場では、仕込み品や開封済み食材の期限管理が目視や手書きラベルに依存しがちで、チェック漏れによる廃棄ロスが発生しやすい課題があります。  
また、廃棄した食材の原価損失が即座に集計されないため、仕込み量の適正化に向けた振り返りが難しい状態でした。

本システムは、**「賞味期限アラートによる先入れ先出しの徹底」** と **「廃棄処理時の原価損失自動集計」** をシンプルなCUI操作で実現し、現場のオペレーション負荷軽減と店舗のロス削減を支援します。

---

## 主な機能 (CRUD + レポート)

* **[1] 食材・仕込み品登録 (Create)**
  * 品名、カテゴリ、数量、単位、単価（原価）、消費期限を対話形式で登録。
* **[2] 在庫一覧・期限アラート表示 (Read)**
  * `java.time.LocalDate` を用いて現在日との差分を自動判定。
  * 「良好」「注意（残り2日以下）」「本日中（優先消費）」「期限切れ（要廃棄）」のステータスを出力。
* **[3] 在庫数量・期限の更新 (Update)**
  * 仕込み品の消費に伴う残数減算、数量の上書き、賞味期限の延長・変更。
* **[4] 廃棄処理・ログ移動 (Delete)**
  * 期限切れ等の食材を指定数だけ廃棄。在庫から減算/削除し、廃棄理由とともに「廃棄履歴」へ自動転送。
* **[5] 廃棄ロス集計レポート (Report)**
  * 廃棄ログから累計廃棄件数および原価ベースの「累計損失総額（¥）」を即座に集計・可視化。

## 設計・技術的な工夫点

* **責務に応じたパッケージ分割（オブジェクト指向設計）**
  * `model`: データ構造の保持（`StockItem`, `WasteLog`）
  * `service`: 業務ロジック・集計計算（`StockService`, `WasteService`）
  * `util`: 入力検証・クラッシュ防止ハンドリング（`InputUtil`）
  * `main`: アプリケーションの実行制御・メニューループ（`Main`）
* **堅牢な入力バリデーション**
  * 数値入力欄への文字列入力や不正な日付フォーマットに対して `try-catch` による再入力ループを実装し、CLI特有の異常終了を防止。
* **Spring Boot（Web化）への拡張性**
  * 業務ロジックと画面入出力（I/O）を疎結合に保つことで、後期のWebフレームワーク導入時にService層のロジックをそのまま再利用できる構成を採用。
